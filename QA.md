# Приёмка версии 4.0

- [x] Старые ID, история, шаблоны и комплексы сохраняются.
- [x] Новый ввод не требует подтверждений.
- [x] Копии и шаблоны создают неподтверждённые заготовки, включая итог и круги комплекса.
- [x] Просмотр и изменение параметров не подтверждают выполнение.
- [x] Частичное завершение сохраняет только фактическую работу; полностью пустое выполнение не создаёт занятие.
- [x] Целевое число кругов отличается от выполненных кругов; подтверждения подхода/круга/итога независимы.
- [x] JSON 3 восстанавливает обычный черновик и правку истории отдельно, включая шаблоны и каталог.
- [x] Конфликт исходной версии исторической тренировки блокирует импорт без записи поверх данных.
- [x] JSON 1/2 продолжают импортироваться; их записи не становятся заготовками.
- [x] Время поддерживает секунды и мин:сек; хранение осталось в секундах.
- [x] Удалённый подход восстанавливается на исходную позицию со всеми параметрами; истечение отмены явно обозначено.
- [x] Сворачивание не меняет результаты; предыдущая последовательность доступна рядом.
- [x] Первые три предложения по возможности различаются основными паттернами.
- [x] Пройдены обновление прежней PWA, мобильные сценарии 390×844, офлайн, библиотека и аналитика.
- [ ] Физический iPhone: клавиатура времени, установленная PWA, обновление и импорт через «Файлы».

Автоматические сценарии: tests/v4.cjs, tests/v4-browser.cjs и регрессии tests/*-browser.cjs. Скриншоты и личные JSON не публикуются в репозитории.
