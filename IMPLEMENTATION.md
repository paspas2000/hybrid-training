## Этап 2 — ввод и попытки реализованы
- В дополнительных параметрах записи: необязательные успешные/неудачные попытки; итог вычисляется, повторы остаются самостоятельным показателем. Отключение учёта удаляет результаты.
- Старые записи не получают выдуманный результат. Для частично известной истории процент считается только по учтённым попыткам.
- Необязательный тип: разминка, техника, рабочий; без автоматического вывода об интенсивности.
- Добавлен порядок записей ↑/↓. При добавлении следующей записи фокус и выделение первого числового поля ускоряют смену веса.
- Следующая/прошлая запись копирует нагрузку и тип без результатов попыток. Повтор тренировки и запуск шаблона также очищают результаты попыток. Редактирование истории сохраняет их.
- Новые необязательные поля сохраняются существующим JSON версии 2, в истории, черновике и шаблонах; обновление структуры IndexedDB не требуется. Старые версии приложения эти поля не поддерживают.
- В статистике доступны успешные, неудачные, всего и процент учтённых попыток; дневной процент считается из суммы попыток, а не среднего процентов.
- `node tests/stage2.cjs`: проверены модель, валидация, JSON roundtrip, старая история, расчёты, силовые/свой вес/бег/комплекс/шаблон.
- `node tests/stage2-browser.cjs` (Playwright, установленный Edge): мобильный viewport 390×844, ввод/копирование/перезагрузка, редактирование истории, повтор без переноса результатов, отсутствие горизонтального переполнения, офлайн-перезагрузка, отсутствие ошибок JS. Это эмуляция, не проверка физического iPhone.
- PWA: версия оболочки v3.2.0. Изменения пока локальные, без публикации.
