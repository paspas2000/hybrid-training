# Гибрид — универсальный дневник тренировок

Офлайн PWA для iPhone и GitHub Pages. HTML, CSS и JavaScript без сборки, сервера и внешних зависимостей. Данные хранятся только в IndexedDB браузера.

## Как устроен дневник

Тренировка содержит четыре секции: навык/мощность, сила, работоспособность/прикладная сила и выносливость. В каждой можно добавить несколько упражнений, менять их порядок кнопками ↑ и ↓ и создавать свои упражнения. Внутри упражнения — отдельные записи. В каждой записи можно заполнить только нужные поля: вес, дополнительный вес, повторы, время, дистанцию, круги и заметку. Время вводится в минутах и сохраняется в секундах; дистанция вводится в метрах или километрах и сохраняется в метрах. Поля выбираются через «Поля записи» и запоминаются для упражнения. Необязательное поле «Вариант выполнения» позволяет различать, например, рывок с виса, фронтальный присед и интервальный бег без дублирования упражнений в библиотеке.

Кнопки «+ Запись» и «Дублировать последнюю» ускоряют ввод. После сохранения тренировки под упражнением показывается последний результат, а кнопка «Взять прошлую запись» копирует его в новый черновик. Пустые записи при завершении пропускаются. Заметка к упражнению подходит для состава комплекса, а заметка к записи — для отдельного подхода или интервала.

Статистика использует те же поля для всех упражнений: активность по дням за год, разбор отдельной тренировки по записям и история упражнения с графиком по дням. В разборе видны количество записей, максимальный вес, суммарные повторы и график каждого заполненного поля по порядку записей. В статистике упражнения можно выбрать вариант выполнения и доступный показатель. Если в день было несколько тренировок, их записи объединяются для дневного показателя. Объём «вес × повторы» можно включить для конкретного упражнения. Темп рассчитывается, когда в одной записи есть время и дистанция. Специальных режимов для ТА, гирь или бега нет.

Сохранённую тренировку можно удалить из истории после подтверждения. Она исчезнет и из статистики. Восстановить её можно только из JSON-экспорта, сделанного до удаления.

Библиотека содержит четыре блока. Прыжки на тумбу находятся в «Работоспособности / прикладной силе»; взрывное исполнение можно пометить вариантом. Скакалка находится в «Выносливости». Круговая работа не предлагается как отдельное упражнение: добавь её составные упражнения и объедини их в связку. Старые ID сохранены, включая исторические записи с прежним распределением по блокам.

Для прыжков на тумбу начальное поле — только повторы; время можно включить через «Поля записи», если оно измерялось. Пустое время не мешает сохранить запись: статистика повторов и количества записей продолжит считаться, а пропуск времени останется пропуском на графике. Для подтягиваний и брусьев «Доп. вес» заполняется только при дополнительном отягощении. Пустое поле означает отсутствие записанного дополнительного веса; повторы учитываются, вес тела отдельно не измеряется и не прибавляется к объёму.

## Смысл нагрузки и организация тренировки

У записи с обычным весом можно уточнить, как он указан: общий вес, вес на одну руку или на один снаряд. Если способ не указан, старые числа остаются без новой интерпретации. Максимум и объём не смешивают записи с разными способами указания веса; в статистике упражнения появляется фильтр по этому признаку. Для упражнений с собственным весом можно отмечать обычное выполнение, дополнительный вес или помощь. Пользовательское упражнение тоже можно пометить как упражнение с собственным весом в «Полях записи». Вес тела автоматически не вычисляется.

Оценка сложности всей тренировки от 1 до 10 необязательна. Она сохраняется вместе с тренировкой и показывается в отдельном графике; общий «балл нагрузки» не рассчитывается. После добавления как минимум двух упражнений кнопка «Объединить» позволяет создать связку между любыми блоками, указать название, число кругов, отдых и заметку. Упражнения и их записи остаются самостоятельными.

В выборе упражнений есть избранное, недавно выполненные упражнения и фильтр по инвентарю. Варианты выполнения предлагаются кнопками из прошлых записей и сохраняются для быстрого повторного выбора. Пользовательскому упражнению можно указать инвентарь при создании.

## Публикация через GitHub Pages

1. Загрузи **содержимое** этой папки в корень публичного репозитория GitHub. `index.html`, `model.js`, `app.js` и остальные файлы должны быть в корне, папка `icons/` — рядом с ними.
2. В репозитории открой **Settings → Pages → Build and deployment**. Выбери **Deploy from a branch**, ветку `main`, папку `/(root)` и сохрани.
3. Дождись успешной публикации в **Actions**. Сайт будет по адресу вида `https://USERNAME.github.io/REPO/`.
4. На iPhone открой этот HTTPS-адрес в Safari, нажми **Поделиться → На экран Домой**. Первый запуск сделай с интернетом, чтобы установился офлайн-кэш.

Для этого проекта адрес: https://paspas2000.github.io/hybrid-training/ . Исходники сайта публичны; твои тренировки в GitHub не отправляются.

Рабочий репозиторий находится в `/Users/anton/Documents/Projects/hybrid-training`. После изменений проверь файлы, создай коммит и выполни `git push origin main`; GitHub Pages публикует эту ветку.

## Данные и перенос

**Данные → Скачать JSON** сохраняет историю, черновик и настройки упражнений. **Выбрать JSON** принимает экспорт версии 1 или 2. Новые тренировки добавляются, одинаковые ID с одинаковым содержимым пропускаются, различающиеся записи с одинаковым ID блокируют импорт. Непустой текущий черновик сохраняется.

При первом запуске версии 2 старые записи автоматически преобразуются в модель с отдельными записями. Исходные данные остаются в `legacySnapshot` внутри IndexedDB и включаются в новый JSON-экспорт. Старая запись с 3 подходами × 5 повторами станет тремя записями по 5 повторов. Если в старой записи время было общим для нескольких подходов, оно остаётся в заметке упражнения, поскольку распределить его по подходам без догадки нельзя.

На разных устройствах и между Safari и установленной PWA автоматической синхронизации нет. При смене устройства, адреса или очистке данных сайта переноси историю через JSON. Сохраняй резервную копию регулярно; она содержит записи открытым текстом.

## Локальный запуск

Открывай через localhost, а не `file://`, чтобы service worker работал:

```sh
cd /Users/anton/Documents/Projects/hybrid-training
python3 -m http.server 8080 --bind 127.0.0.1
```

После изменения файлов приложения увеличивай `VERSION` в `service-worker.js`. Старая открытая вкладка покажет кнопку «Обновить» после загрузки новой версии.

## Файлы

- `index.html`, `styles.css` — интерфейс;
- `data.js` — секции и встроенные упражнения;
- `model.js` — структура, проверка, перенос старой истории и универсальная статистика;
- `db.js` — IndexedDB;
- `app.js` — ввод и действия пользователя;
- `manifest.json`, `service-worker.js`, `icons/` — установка и офлайн-режим.
