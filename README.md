# Гибрид — дневник тренировок

Офлайн-приложение для iPhone и браузера: HTML/CSS/JavaScript, IndexedDB, GitHub Pages. Без аккаунта и автоматической синхронизации.

## Версия 5.3

На главном экране четыре цветных блока: **Мощность**, **Сила**, **Работоспособность**, **Выносливость**. Открой блок, добавь упражнения или комплекс и записывай выполненное. Запуск секундомера необязателен и не ограничивает добавление, изменение или удаление упражнений.

Вверху блока — секундомер. «Начать / продолжить» запускает отсчёт, повторное нажатие останавливает его. Одновременно работает один секундомер: запуск другого останавливает предыдущий. Просмотр других блоков и страниц не переключает отсчёт. Повторное выполнение блока добавляет новый отрезок к сохранённому времени. Начало показывается в часовом поясе устройства.

Время рассчитывается по сохранённой отметке запуска, поэтому фон, закрытая вкладка и перезагрузка не сбрасывают отсчёт. Пока блок не остановлен, время продолжает идти; его можно исправить вручную в секундах или `мин:сек`. Завершение тренировки останавливает активный секундомер. Историческое время исправляется вручную; отдельный текущий черновик при редактировании истории сохраняется.

В мощности записываются только выполненные подходы: вес и повторы. Удачные/неудачные попытки и тип подхода выбирать не нужно. В силе одна строка хранит вес, повторы в подходе и число подходов (по умолчанию 1): например, 80 кг × 10 × 3. «+ Подход» добавляет пустую строку, «Копировать» — последнюю строку текущего упражнения. Копирования из прошлой тренировки нет. При другом весе добавляется отдельная строка. Статистика умножает повторы, время и дистанцию на число подходов; вес не умножается. Старые строки без числа подходов считаются одним подходом. Оценки, заметки к упражнениям и подходам, подсказки и типы подходов убраны с экрана. Общая заметка свёрнута. Старые оценки и заметки сохраняются в данных и резервных копиях. В шаблон и повтор тренировки не переносится время выполненного.

## Статистика — четыре раздела

1. **Активность за год:** сетка по дням, как в GitHub; цвет отражает количество сохранённых тренировок.
2. **Упражнения:** поиск по выполненным упражнениям, показатель, линия или столбцы. Периоды: неделя, месяц, 6 месяцев, год, всё время. Варианты и способы указания веса выбираются отдельно, когда они различаются. Показатели за день: максимальный вес, дополнительный вес, сумма повторов/времени/дистанции, число записей, темп или успешность известных попыток. Вес/повторы не превращаются в оценку физической готовности.
3. **Время тренировки:** выбор занятия, круговая диаграмма измеренного времени, длительность каждого блока.
4. **Время по блокам:** четыре цветные линии, минуты за день, выбранный период. Неизмеренные значения остаются пропусками; нулём считается только явно записанное нулевое время.

Старые тренировки не получают придуманную длительность. Секторы круговой диаграммы показывают только измеренное время. Нет матрицы прогресса, текстовых автоматических оценок, e1RM, модели восстановления и баллов нагрузки.

## Упражнения и запись

Каталог организован в 21 раскрываемую группу (6/6/5/4); поиск общий. Группа служит папкой выбора, а конкретные упражнения и снаряды сохраняют собственные ID и историю. Направление выполнения можно выбрать отдельно. Свои упражнения, избранное, скрытие и настройки полей сохранены. Старые скрытые упражнения доступны в настройках и истории.

У каждого упражнения есть один из шести профилей записи. Профиль задаётся в библиотеке, во время тренировки переключателей полей и способа веса нет.

| Тип | Поля |
| --- | --- |
| Вес и повторы | Вес, повторы |
| Свой вес | Повторы, необязательный доп. вес |
| Повторы | Повторы; доп. вес для соответствующих упражнений |
| Удержание | Время; вес для удержания груза |
| Перенос / перемещение | Вес, дистанция; время при включении в профиле |
| Кардио | Время; дистанция для соответствующих упражнений |

Вес штанги включает гриф. Для гирь и гантелей записывается масса одного снаряда. Фермерская прогулка по умолчанию — две гири: ввод 32 означает две гири по 32 кг. Сани используют вес добавленных блинов, собственный вес — дополнительное отягощение. Поле имеет конкретную подпись, например «Вес одной гири, кг». Количество снарядов задаётся один раз в профиле библиотеки, не в подходе. В библиотеке можно изменить тип, правило веса, инвентарь, число снарядов, единицы дистанции и вариант по умолчанию. Свободный ввод варианта/формата, галочки полей и выбор способа веса удалены из тренировки; меню «⋯» содержит перенос между блоками и порядок.

Новое упражнение хранит снимок профиля. Изменение библиотеки влияет на добавляемые упражнения, а не на сохранённую историю, шаблоны или уже начатую запись. Старые записи без снимка сохраняют прежние значения и явно указанный способ веса; отсутствующий способ не угадывается. В графиках старый неуточнённый вес, новый вес одного снаряда и разное число снарядов выбираются отдельно.

Новый комплекс: дай название (по умолчанию «Комплекс»), выбери подряд упражнения в каталоге и нажми «Готово». У каждого упражнения — компактные поля выбранного круга. «Повторить круг» создаёт новый круг с копией введённых значений; их можно изменить отдельно. Переключатель показывает любой круг. Удаление круга допускает отмену, если после удаления записи не менялись. При добавлении упражнения в поздний круг предыдущие круги не заполняются автоматически. Шаблонные значения требуют подтверждения выполнения. Каждая запись считается один раз, круги дополнительно не умножают объём. Старые комплексы открываются в прежней структуре без искусственного распределения подходов по кругам.

Введённое с нуля считается фактом. Запуск шаблона или повтор занятия создаёт заготовки: пока они не подтверждены, их значения не попадают в историю и статистику. Неизвестные исходы попыток не считаются успешными. Число кругов само по себе не умножает фактические записи упражнений.

## Хранение и резервные копии

История находится в IndexedDB этого браузера. Safari, установленная PWA и другие устройства могут иметь отдельные данные. Очистка данных сайта удаляет локальную историю.

Экспорт **версии 6** сохраняет историю, время и оценки, текущий черновик с активным секундомером, отдельную правку истории, шаблоны, каталог и прежнюю исходную копию. Импорт принимает версии 1–6. Новый номер экспорта защищает профили записи от потери при попытке прочитать файл старым приложением. Модель тренировки остаётся версии 2 с дополнительными полями; структура IndexedDB не меняется.

Одинаковые записи пропускаются; различающиеся записи с одинаковым ID блокируют импорт. Непустой черновик и конфликтующая правка истории защищены. После восстановления активного секундомера проверь прошедшее время и при необходимости исправь его.

## Запуск и публикация

Локально: `python3 -m http.server 8080 --bind 127.0.0.1`, затем открыть `http://127.0.0.1:8080/`. Запуск через `file://` не обеспечивает PWA.

GitHub Pages публикует корень `main`: https://paspas2000.github.io/hybrid-training/ . На iPhone: Safari → «Поделиться» → «На экран Домой». Первый запуск — с интернетом, до отметки «Офлайн готов».

Оболочка v5.3.1 включает `timing.js` и `simple-stats.js`. После изменений оболочки увеличивай `VERSION` в `service-worker.js`. Обновление не очищает базу; при несохранённой правке истории сначала сохрани или отмени её.

## Проверки

`node tests/run.cjs` — модель, каталог, старые данные и таймеры.

`node tests/run.cjs --browser` — дополнительно шесть сквозных браузерных сценариев: текущая работа, каталог/импорт и обновление с Git-версии 5.0. Требуются Playwright и установленный Chrome; `HYBRID_BROWSER` выбирает другой канал. Производственному приложению эти зависимости не нужны.

Тестовые браузеры используют отдельные профили. Проверяются мобильная и настольная ширина, фон/перезагрузка/офлайн, редактирование, копирование, круги комплекса, JSON, старые версии, конфликты и обновление. Физический iPhone этими сценариями не заменяется.

## Импорт исправлений истории
Специальный файл версии 6 может содержать `historyCorrections`: исходные версии тренировок, а в `history` — исправленные с теми же ID. Предпросмотр показывает число замен и даты. Заменяется только точное совпадение с исходной версией; более новая правка блокирует импорт. Повторная загрузка уже применённого файла ничего не меняет. Транзакция повторно проверяет исходные версии перед записью. Обычные резервные копии по-прежнему не перезаписывают конфликтующие ID. Обратный файл меняет местами исходные и исправленные версии.
