# Ревизия библиотеки по материалам трёх видео

Материал: предоставленная пользователем объединённая текстовая расшифровка. Это идеи для библиотеки, а не нормативная программа и не проверенная научная база. Утверждения о процентах, исследованиях, профилактике травм и обязательных соотношениях к массе тела не использованы в приложении.

| Идея материала | Решение для «Гибрида» |
|---|---|
| Различать силу, мощность, скорость и координацию | Сохранены четыре блока; добавлены отдельные основные и дополнительные качества упражнений. Они описывают назначение, а не измеряют уровень подготовки. |
| Жим, push press, подтягивания, горизонтальные тяги | Сохранены полноценными вариантами выбора. Хваты, гантели, наклон и опора грудью — подсказки вариантов без слияния истории. |
| Румынская тяга и гиперэкстензия | Обе доступны; становая тяга сохранена. Предпочтения автора не превращены в запреты. |
| Прыжки, реактивные подскоки, смена направления | Различены профили: мощность, реактивность и координация. Реактивность не назначается всем прыжкам автоматически. Фактическое исполнение потребует уточнения в будущей аналитике. |
| Прогрессии выпадов и взрывных отжиманий | Сохранены базовые упражнения; добавлены подсказки исполнения. Не создаётся отдельное упражнение под каждую ступень. |
| Скипы | Добавлены в дополнительный список блока 01: координация всего тела и продвижение. Не смешаны с подскоками на месте. |
| Броски штанги в Смите, сложные X-отжимания, баланс на трубе | Не добавлены в основной каталог: специализированные исполнения не обязательны для универсального дневника. При необходимости доступны пользовательские упражнения. |
| Интервальный протокол на гребле/велосипеде/AirBike | Используются существующие упражнения и записи времени; название протокола не становится отдельным упражнением. |
| Игровая практика и индивидуальные цели | Учесть при персонализации; не пытаться свести спортивный навык к одному баллу или обязательному набору упражнений. |

Ни одно прежнее упражнение не удалено; ID, названия и принадлежность прежних упражнений к блокам сохранены. Избранное дополнительное упражнение доступно без раскрытия полного списка.

Управление пользовательской видимостью (в том числе скрытие) остаётся этапом 3. Мобильная и офлайн-проверка требуют отдельного браузерного прогона; они не считаются выполненными этой ревизией.
